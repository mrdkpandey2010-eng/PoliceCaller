# 🛡️ Uttar Pradesh Police Portal - Project Backup & 1-Click Setup Guide
### (उत्तर प्रदेश पुलिस निर्देशिका - प्रोजेक्ट बैकअप एवं वन-क्लिक सेटअप निर्देश)

## 📦 1. इस बैकअप में क्या-क्या शामिल है? (Backup Contents)

इस बैकअप में प्रोजेक्ट की सभी फाइलें तथा होस्ट (Cloudflare D1) का **100% लाइव डेटा** प्रोजेक्ट फोल्डर में पहले ही कॉपी कर दिया गया है ताकि आपको भविष्य में होस्टिंग या क्लाउड के भरोसे न रहना पड़े:

1. **लाइव डेटाबेस डंप (Complete Host Data):**
   - `database_backup.sql` — क्लाउड होस्ट से एक्सपोर्ट किया गया पूरा SQL डेटाबेस (सभी 75 जिले, 2,179 थाने/कार्यालय, सभी पुलिस अधिकारी एवं लॉग)।
   - `local_database.sqlite` — किसी भी कंप्यूटर पर बिना इंटरनेट के तुरंत काम करने के लिए तैयार ऑफलाइन SQLite डेटाबेस।
2. **वेब एवं मोबाइल PWA ऐप (Full Frontend Source):**
   - `apps/web/` — संपूर्ण यूज़र इंटरफ़ेस, डायरेक्टरी, मैसेंजर, एडमिन कंसोल, नोटिस बोर्ड।
   - `apps/web/public/` — आधिकारिक ऐप आइकॉन (`icon-192.png`, `icon-512.png`, `maskable-512.png`, `shield.svg`)।
3. **बैकएंड API गेटवे (Cloudflare Worker & Local Engine):**
   - `apps/api/` — सभी सुरक्षित API रूट्स, RBAC परमिशन, एक्सेल इंपोर्ट, ऑथेंटिकेशन, ट्रांसफर इंजन।
4. **शेयर्ड पैकेजेस एवं UI कंपोनेंट्स:**
   - `packages/shared/` & `packages/ui/`
5. **एंड्रॉइड नेटिव सपोर्ट:**
   - `android/` — एंड्रॉइड स्टूडियो नेटिव ऐप प्रोजेक्ट।
6. **ऑटोमेशन स्क्रिप्ट्स:**
   - `1-CLICK-SETUP-AND-START.bat` — किसी भी नए कंप्यूटर पर बिना किसी सॉफ्टवेयर के 1-क्लिक में प्रोजेक्ट चलाने वाली स्क्रिप्ट।
   - `send-backup-to-telegram.bat` & `send_to_telegram.py` — टेलीग्राम पर तुरंत बैकअप भेजने का टूल।

## ⚡ 2. किसी भी अन्य कंप्यूटर पर 1-क्लिक में कैसे चलाएं? (One-Click Setup)

आपको दूसरे कंप्यूटर पर **कोई भी अलग से सॉफ्टवेयर या टूल्स इंस्टॉल करने की आवश्यकता नहीं है**:

1. अपने बैकअप फोल्डर को किसी भी पेनड्राइव या डाउनलोड से दूसरे कंप्यूटर पर कॉपी करें।
2. फोल्डर में मौजूद **`1-CLICK-SETUP-AND-START.bat`** पर **डबल क्लिक (Double Click)** करें।
3. यह स्क्रिप्ट स्वचालित रूप से:
   - यदि कंप्यूटर पर Node.js नहीं है, तो पोर्टेबल Node.js अपने आप डाउनलोड करके सेटअप कर देगी (एडमिनिस्ट्रेटर परमिशन की भी जरूरत नहीं)।
   - प्रोजेक्ट डिपेंडेंसीज़ (npm packages) खुद इंस्टॉल कर लेगी।
   - लोकल डेटाबेस लोड करेगी।
   - सीधे ब्राउज़र में **http://localhost:5173** पर ऐप खोल देगी।

## ✈️ 3. टेलीग्राम पर बैकअप कैसे भेजें? (Telegram Delivery)

प्रोजेक्ट की पूरी ज़िप फाइल तैयार है:
- **फाइल:** `police_directory_backup.zip` (आकार: मात्र ~0.8 MB)

### विकल्प A: चैट में बॉट टोकन देकर (Direct via Assistant):
यदि आप चैट में अपना **Telegram Bot Token** (जैसे `123456789:ABCdef...` जो @BotFather से मिलता है) और अपना **Chat ID** (जैसे `987654321`) प्रदान करते हैं, तो मैं सीधे इसे आपके टेलीग्राम पर भेज दूँगा।

### विकल्प B: खुद 1-क्लिक में अपने टेलीग्राम पर भेजने के लिए:
1. फोल्डर में मौजूद **`send-backup-to-telegram.bat`** पर डबल-क्लिक करें।
2. स्क्रीन पर अपना **Bot Token** और **Chat ID** दर्ज करें।
3. बैकअप ज़िप फाइल सीधे आपके टेलीग्राम इनबॉक्स / चैनल में पहुँच जाएगी।
